# 目录说明：docs

## 1. 目录职责

本目录保存 AutoWaterSimu 的产品、架构、设计、教程和迁移文档。

本目录负责：

- 长期产品与架构说明。
- 重构计划、技术规格和开发计划。
- 教程、模型说明和评审记录。

本目录不负责：

- 源码实现。
- 运行时配置。
- 临时任务进度。

## 2. 核心文件

| 文件/子目录 | 作用 |
|---|---|
| `rebuild/` | AutoWaterSimu Next 重构文档 |
| `tutorial/` | 教程文档 |
| `UDM/` | UDM 相关文档 |

## 3. 维护约定

1. 架构和长期产品判断放入 `docs/`。
2. 单次任务过程记录放入 `tasks/` 或 `.ai/changes/`。
3. 文档必须基于当前代码和已确认计划，不写未经确认的事实。

## 4. 对外接口

本目录对开发者和 Agent 暴露长期项目上下文。

## 5. 依赖边界

文档可引用代码路径和外部资料，但不应依赖生成产物。

## 6. 测试与验证

修改文档后建议运行：

```powershell
git diff --check -- docs
```

## 7. AI 操作提示

修改重构文档前先读 `docs/rebuild/README.md`。
