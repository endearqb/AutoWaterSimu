# 目录说明：.ai/decisions

## 1. 目录职责

本目录保存长期架构决策。

## 2. 核心文件

| 文件 | 作用 |
|---|---|
| `0001-*.md` | 编号架构决策记录 |

## 3. 维护约定

1. 决策应说明背景、决定、影响和替代方案。
2. 文件名使用递增编号。
3. 普通任务记录不要写入本目录。

## 4. 对外接口

对未来架构和实现提供决策依据。

## 5. 依赖边界

记录长期事实，不记录临时实现细节。

## 6. 测试与验证

修改后运行 `git diff --check -- .ai/decisions`。

## 7. AI 操作提示

遇到与现有决策冲突的需求，先指出冲突再计划修改。
