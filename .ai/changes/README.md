# 目录说明：.ai/changes

## 1. 目录职责

本目录记录每次重要修改的原因、范围、假设和验证。

## 2. 核心文件

| 文件 | 作用 |
|---|---|
| `YYYY-MM-DD.md` | 当日变更记录 |

## 3. 维护约定

1. 标题格式为 `## HH:MM - <任务标题>`。
2. 记录用户目标、涉及目录、修改内容、原因、验证和剩余不确定性。
3. 不替代 git diff。

## 4. 对外接口

对后续维护者暴露变更背景。

## 5. 依赖边界

不保存敏感数据。

## 6. 测试与验证

修改后运行 `git diff --check -- .ai/changes`。

## 7. AI 操作提示

每次记录保持短而具体。
