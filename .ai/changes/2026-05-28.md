## 00:12 - Phase 4A Go Compute API skeleton

- 用户目标：按 PRD/Spec/Development Plan 实现 Web Compute API P0A skeleton，并在开始前 checkpoint Phase 3C Desktop dev MVP。
- 涉及目录：`apps/api/`、`frontend/src/client/`、`frontend/`、`.ai/decisions/`、`tasks/`。
- 修改内容：新增 Go Compute API module、PostgreSQL migration、job/worker/artifact lifecycle service、static token scope auth、OpenAPI spec、compute TS client generation config 和 generated client。
- 修改原因：`apps/api/` 仍为空 skeleton，Web / Platform 线缺少与 Desktop/Worker 共用合同的任务编排入口。
- 本次已消除的不确定性：确认 Web metadata DB 使用 PostgreSQL；Go API 使用 `net/http` + `pgx/v5`；P0 auth 使用 static token scopes；artifact P0 使用 local filesystem abstraction。
