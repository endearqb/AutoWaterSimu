# 目录说明：tasks

## 1. 目录职责

本目录保存任务计划、阶段性工作记录、教程开发说明和历史执行材料。

本目录负责：

- `todo.md` 中的当前任务计划和复盘。
- 历史开发计划。
- 任务型研究报告。

本目录不负责：

- 长期架构决策。
- README First 变更记录。
- 业务源码。

## 2. 核心文件

| 文件 | 作用 |
|---|---|
| `todo.md` | 当前和历史任务 checklist / review |

## 3. 维护约定

1. 非简单任务先在 `todo.md` 记录计划。
2. 完成后在同一任务条目下写 Review。
3. 长期架构决策不要只写在 `tasks/`，应同步 `.ai/decisions/`。
4. `lessons.md` 是可选经验沉淀文件；若存在则在相关任务前读取，不存在时不要为普通任务空建。

## 4. 对外接口

本目录对 Agent 和开发者暴露任务上下文。

## 5. 依赖边界

任务记录可引用代码和文档路径，不应成为唯一权威架构来源。

## 6. 测试与验证

修改任务文档后建议运行：

```powershell
git diff --check -- tasks
```

## 7. AI 操作提示

不要删除历史任务记录；新增当前执行任务按现有 `todo.md` 约定放到文件顶部，任务完成后在同一条目下补 Review。
